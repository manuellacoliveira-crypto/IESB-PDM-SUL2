# Atividade-screen

Projeto Expo/React Native para a atividade de navegação com React Navigation.

## Estrutura

- `App.js` — Native Stack + Bottom Tabs
- `screens/DespesasRecentes.js`
- `screens/TodasDespesas.js`
- `screens/GerenciarDespesa.js`
- `components/IconButton.js`

## Instalação

Na raiz do projeto:

```bash
npm install
```

Depois:

```bash
npx expo start
```

## Branch sugerida

```bash
git checkout -b feature/atividade-screen
```

## Navegação

- Bottom Tabs:
  - Recentes
  - Todas
- Native Stack:
  - Despesas
  - GerenciarDespesa
- O botão no cabeçalho abre `GerenciarDespesa`.
